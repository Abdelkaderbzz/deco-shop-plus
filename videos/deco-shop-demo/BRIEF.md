## Intent

Demo / tour vidéo du site Deco Shop Plus (https://www.decoshopplus.com) en format Stories.
Montrer le site tel qu’il est : zoom in / zoom out sur les écrans, mise en avant des
fonctionnalités clés, avec sous-titres français (sans voix off) et musique d’ambiance.

## Assets

- Capture du site live (homepage, catalogue, fiche produit, couleurs, panier / commande).

## Customizations

- Zoom in / zoom out sur les captures d’écran.
- Highlight des fonctionnalités (catalogue, couleurs, panier, commande).
- Captions françaises uniquement — pas de narration.
- Musique de fond adaptée (upbeat / lifestyle maison).

## Notes

- Format 9:16 pour Stories / Reels / TikTok.
- Durée cible ~45–60s.
- Parcours recommandé : accueil → produits → détail / couleurs → panier / CTA.
- Revue storyboard avant le build complet.
